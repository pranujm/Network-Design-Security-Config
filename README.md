# Network-Design-Security-Config

Final Project for IBM Coursera - Computer Networks & Network Security

Tasks include:

**Network Design & Subnetting Calculation:**

Designed a structured network topology consisting of a router, switch, and three separate subnets for Administration, Sales, and IT departments. Calculated the appropriate subnet masks, subnet addresses, and IP address ranges based on a 198.51.100.0/24 network. 

**IP Addressing & Network Organization:**

Divided the company's network into logically separated subnets to organize departmental traffic and efficiently allocate available IP addresses. Documented the network addresses, subnet masks, and usable IP ranges for each department.

**Network Traffic Analysis:** 

Captured live network traffic while accessing websites and used Wireshark filters to isolate and examine HTTPS traffic over TCP port 443. Analyzed captured packets to better understand how web traffic flows between a client and external websites.

**Firewall Configuration & Network Security:** 

Configured Microsoft Windows Defender Firewall with Advanced Security to create outbound rules restricting specific network services. Implemented rules to block FTP traffic over TCP Port 21 and HTTP traffic over TCP Port 80.

**Security Verification:** 

Tested network connectivity before and after implementing firewall rules to verify that FTP and HTTP traffic could be successfully restricted. Documented the configuration and results through screenshots demonstrating the effectiveness of the security controls.
